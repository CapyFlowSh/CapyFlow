# Importando Projetos

Se você recebeu ou já possui um arquivo ".capy", pode importá-lo para continuar trabalhando no workflow salvo.

O CapyFlow também aceita arquivos ".json".

## Como importar

Na tela inicial do CapyFlow:

1. Clique em Importar projeto.
2. Selecione o arquivo ".capy" ou ".json" que deseja importar.
3. O projeto será aberto no editor.

Depois de importar, você poderá editar os blocos normalmente e executar o workflow.

# Importando um projeto compartilhado

Arquivos ".capy" podem ser compartilhados entre usuários.

Por exemplo, se alguém enviar um arquivo "meu-projeto.capy", basta abrir o CapyFlow e utilizar Importar projeto para carregar o workflow.

Formatos aceitos

O CapyFlow aceita os seguintes formatos:

- ".capy" — formato padrão de projetos do CapyFlow.
- ".json" — formato JSON compatível com os projetos.

# ⚠️ Atenção

Só importe arquivos de fontes em que você confia.

Um projeto pode conter blocos que geram comandos Shell e, ao ser executado, esses comandos serão executados no sistema.
