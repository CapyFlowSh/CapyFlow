# Como criar um projeto
com o CapyFlow acesse o IP na porta 6060(IP:6060) e clique em criar projeto e crie seu primeiro projeto.

# No editor

dê uma olhada nos blocos no canto esquerdo, tem várias categorias disponíveis:

1. pegue um bloco
2. arraste o bloco para o bloco de início.
3. após pegar seu primeiro bloco adicione mais blocos e assim crie uma sequência de comandos
4. execute
5. Veja a saída no terminal no canto inferior direito.
6. explore mais
7. salve em .capy
