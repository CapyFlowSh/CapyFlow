# Como criar um projeto
com o CapyFlow acesse o IP na porta 6060(IP:6060) e clique em criar projeto e crie seu primeiro projeto.

# No editor

dê uma olhada nos blocos no canto esquerdo, tem várias categorias disponíveis, pegue um bloco e arraste para o bloco de início.
após pegar seu primeiro bloco adicione mais blocos e assim crie uma sequência de comandos que pode ser salva em .capy pelo botão salvar.
